# 客户端扁平界面检查记录

## 界面调整

- 深灰背景、蓝紫色操作按钮、左侧图标栏与房间导航。
- 聊天内容居中，成员列表在右侧；房间配置独立为设置页。
- 语音、电脑声音和屏幕共享分组展示，观看端画质与帧率控制保留。
- 房间状态使用实际连接的角色；成员编号在主机名前保留。
- 连接失败自动切到设置并滚动至顶部；关闭帧率统计不残留空背景。

## 检查结果

使用本项目的 `.build/relaynet.mod` 与 Fyne 120 Hz 绘制补丁构建。

- `go test -p 1 -modfile .build/relaynet.mod ./... -count=1 -timeout=90s`：通过（GOMAXPROCS=2）。
- 导航切换、1024×720 最小布局、标题说明宽度、协议/角色切换、播放设置、错误定位、帧率开关、成员编号与实际角色检查：通过。
- 滚动后错误提示不可见、主机名导致编号消失、角色被草稿设置覆盖三个回归，均先复现失败，再修正并通过。
- `TestLiveScreenPlaybackProfiles`：真实 Windows 窗口通过（GOMAXPROCS=4）。720p/30 在 6 秒内收到 178 帧、4.53 Mbps；1080p/60 收到 354 帧、12.70 Mbps。切换到 1080p/60 后界面统计为 59 FPS，音频/视频会话 ID 保持不变，静止画面切档也通过。
- 五个页面的 Fyne 软件渲染预览检查完成，修正标题截断、用户信息换行与空帧率背景。聊天和观看页预览保存在 `docs/screenshots/`。
- 独立代码审查完成，发现的三个问题已修正并复审。

实机带宽统计包含视频的 IPv4/UDP 开销，不包含音频；接收声音静音。界面帧率统计表示提交画面的速率。
